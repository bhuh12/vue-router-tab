国际化分两部分：**组件自身文案**（`lang` prop）与**页签标题等业务文案**（`i18n` prop）。

## 组件文案：lang

`lang` 类型 `string | Record<string, any>`，默认 `'auto'`。

### 内置语言

内置语言**只有两个**：`zh` 与 `en`。

```vue
<template>
  <RouterTab lang="en" />
</template>
```

<DocLinks :demo="DEMO_ROUTES.LangEn" />

### 自动识别

`lang="auto"`（默认）时取 `navigator.language` 的前两位，未命中内置语言则**回退 `en`**：

```js
// navigator.language = 'zh-CN' → 'zh' → 命中内置 zh
// navigator.language = 'ja-JP' → 'ja' → 未命中，回退 en
```

### 自定义语言对象

传对象时需提供完整结构：

```vue
<template>
  <RouterTab :lang="myLang" />
</template>

<script setup>
const myLang = {
  tab: {
    untitled: '無題'
  },
  contextmenu: {
    refresh: '更新',
    refreshAll: 'すべて更新',
    close: '閉じる',
    closeLefts: '左側を閉じる',
    closeRights: '右側を閉じる',
    closeOthers: '他を閉じる'
  },
  msg: {
    keepLastTab: '少なくとも1つのタブを保持してください',
    i18nProp: '"i18n" メソッドを提供してください'
  }
}
</script>
```

| `msg.keepLastTab`         | 尝试关闭最后一个页签时的提示   |
| `msg.i18nProp`            | 未提供 `i18n` 方法时的警告文案 |

## 业务文案：i18n

页签标题等来自路由 `meta` 的文案，通过 `i18n` prop 交给你的 i18n 库处理：

```ts
i18n?: (key: string, params?: unknown[]) => string
```

### 接入 vue-i18n

```vue
<template>
  <RouterTab :i18n="translate" />
</template>

<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

function translate(key, params) {
  return t(key, params)
}
</script>
```

### meta 中标记 i18n key

两种写法：

```js
// 1. 字符串式：i18n: 前缀
meta: {
  routerTab: {
    title: 'i18n:route.userList'
  }
}

// 2. 数组式：首项为 key，其余为参数
meta: {
  routerTab: {
    title: ['route.userDetail', 'Alice']
  }
}
```

不带 `i18n:` 前缀的普通字符串原样显示，不走翻译。

::: warning 配了 key 但没传 i18n 方法
组件会在控制台警告一次（文案取 `msg.i18nProp`），并把 key 原样显示。
:::

### 动态标题也支持

函数式 `title` 的返回值同样会走 i18n 解析：

```js
meta: {
  routerTab: {
    title: (route) => ['route.page', route.params.id]
  }
}
```

## 手动调用

`useRouterTab()` 暴露了 `i18nText` 与当前语言包：

```js
const tabs = useRouterTab()

tabs.i18nText('i18n:route.userList') // 走 i18n 方法
tabs.i18nText('普通文案') // 原样返回
tabs.langs.tab.untitled // 读当前语言包
```

这在[自定义右键菜单项](./contextmenu#菜单文案国际化)的动态文案里很有用。

## 切换语言

组件语言随 `lang` prop 响应式变化，用 `ref` 驱动即可：

```vue
<template>
  <RouterTab :lang="lang" />
  <button @click="lang = 'en'">English</button>
</template>

<script setup>
import { ref } from 'vue'

const lang = ref('zh')
</script>
```
