国际化 ​

APIDemo

国际化分两部分：组件自身文案（lang prop）与页签标题等业务文案（i18n prop）。

组件文案：lang ​

lang 类型 string | Record<string, any>，默认 'auto'。

内置语言 ​

内置语言只有两个：zh 与 en。

vue
<template>
  <RouterTab lang="en" />
</template>

自动识别 ​

lang="auto"（默认）时取 navigator.language 的前两位，未命中内置语言则回退 en：

js
// navigator.language = 'zh-CN' → 'zh' → 命中内置 zh
// navigator.language = 'ja-JP' → 'ja' → 未命中，回退 en

Lang 类型未导出

库没有导出 Lang 类型，写自定义语言对象时需自行声明结构，或参照上例照抄字段。

字段清单（共 9 项）：

路径说明
tab.untitled无标题页签的占位文案
contextmenu.refresh右键菜单「刷新」
contextmenu.refreshAll右键菜单「刷新全部」
contextmenu.close右键菜单「关闭」
contextmenu.closeLefts右键菜单「关闭左侧」
contextmenu.closeRights右键菜单「关闭右侧」
contextmenu.closeOthers右键菜单「关闭其他」
msg.keepLastTab尝试关闭最后一个页签时的提示
msg.i18nProp未提供 i18n 方法时的警告文案

业务文案：i18n ​

页签标题等来自路由 meta 的文案，通过 i18n prop 交给你的 i18n 库处理：

ts
i18n?: (key: string, params?: unknown[]) => string
1

接入 vue-i18n ​

vue
<template>
  <RouterTab :i18n="translate" />
</template>

<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

function translate(key, params) {
  return t(key, params)
}
</script>

meta 中标记 i18n key ​

两种写法：

js
// 1. 字符串式：i18n: 前缀
meta: {
  routerTab: {
    title: 'i18n:route.userList'
  }
}

// 2. 数组式：首项为 key，其余为参数
meta: {
  routerTab: {
    title: ['route.userDetail', 'Alice']
  }
}

不带 i18n: 前缀的普通字符串原样显示，不走翻译。

配了 key 但没传 i18n 方法

组件会在控制台警告一次（文案取 msg.i18nProp），并把 key 原样显示。

动态标题也支持 ​

函数式 title 的返回值同样会走 i18n 解析：

js
meta: {
  routerTab: {
    title: (route) => ['route.page', route.params.id]
  }
}

手动调用 ​

useRouterTab() 暴露了 i18nText 与当前语言包：

js
const tabs = useRouterTab()

tabs.i18nText('i18n:route.userList') // 走 i18n 方法
tabs.i18nText('普通文案') // 原样返回
tabs.langs.tab.untitled // 读当前语言包

切换语言 ​

组件语言随 lang prop 响应式变化，用 ref 驱动即可：

vue
<template>
  <RouterTab :lang="lang" />
  <button @click="lang = 'en'">English</button>
</template>

<script setup>
import { ref } from 'vue'

const lang = ref('zh')
</script>

完整示例 ​

语言切换 frame：

vue
<template>
  <RouterTab :i18n="i18n" :tabs="tabs" />
</template>

<script setup lang="ts">
import { ref, computed, provide } from 'vue'

import { LANG_KEY, type LangSwitcher } from './I18n.shared'

/** 语言包（对照 v1 frames/I18n.vue） */
const langs: Record<string, Record<string, string>> = {
  en: { i18n: 'I18n Page', page: 'Page {0}' },
  zh: { i18n: '国际化页面', page: '页面 {0}' }
}

/** 当前语言 */
const currentLang = ref('en')

/** 当前语言文案 */
const lang = computed(() => langs[currentLang.value] || langs.en)

/** 初始页签，标题用 i18n key 数组式 */
const tabs = [
  '/i18n/lang',
  { to: '/i18n/page/1', title: ['page', 1] },
  { to: '/i18n/page/2', title: ['page', 2] }
]

/** 翻译函数（对照 v1，支持 {0} 占位符） */
function i18n(key: string, params: any[] = []) {
  const text = lang.value[key]
  return text ? text.replace(/\{(\d+)\}/g, (_m, i) => params[i] ?? '') : key
}

/** 语言切换器（替代 v1 Vue.prototype.$lang），provide 给子页面 */
const switcher: LangSwitcher = {
  set: (l) => (currentLang.value = l),
  get: () => currentLang.value,
  list: () => Object.keys(langs)
}
provide(LANG_KEY, switcher)
</script>

共享的切换器定义：

ts
import type { InjectionKey } from 'vue'

/** 语言切换器（替代 v1 Vue.prototype.$lang，供 I18n frame 与 I18nPage 共享） */
export interface LangSwitcher {
  /** 切换到指定语言 */
  set: (lang: string) => void

  /** 取当前语言 */
  get: () => string

  /** 取所有可选语言 */
  list: () => string[]
}

/** 语言切换器注入 key */
export const LANG_KEY: InjectionKey<LangSwitcher> = Symbol('demo-lang')

自定义语言包：

vue
<template>
  <RouterTab :lang="customLanguage" />
</template>

<script setup lang="ts">
/** 自定义组件语言包（对照 v1 LangCustom.vue） */
const customLanguage = {
  /** 页签相关文案 */
  tab: {
    /** 未命名页签的默认标题 */
    untitled: 'Untitled Page'
  },

  /** 右键菜单文案 */
  contextmenu: {
    /** 刷新 */
    refresh: 'Refresh This',
    /** 刷新全部 */
    refreshAll: 'Refresh All',
    /** 关闭 */
    close: 'Close This',
    /** 关闭左侧 */
    closeLefts: 'Close to the Left',
    /** 关闭右侧 */
    closeRights: 'Close to the Right',
    /** 关闭其他 */
    closeOthers: 'Close Others'
  },

  /** 提示文案 */
  msg: {
    /** 最后一个页签禁止关闭的提示 */
    keepLastTab: 'Keep at least 1 tab',
    /** 未传 i18n prop 却用了 i18n key 时的告警文案 */
    i18nProp: 'Please set the i18n prop of RouterTab'
  }
}
</script>
