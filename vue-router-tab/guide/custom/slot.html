页签插槽 ​

APIDemo

RouterTab 提供三个插槽：

插槽作用域说明
default{ tab, closable }自定义页签项内容
start无页签栏左侧
end无页签栏右侧

自定义页签项 ​

vue
<template>
  <RouterTab>
    <template #default="{ tab, closable }">
      <i v-if="tab.icon" class="router-tab__item-icon" :class="tab.icon" />
      <span class="router-tab__item-title" :title="tab.tips || tab.title">
        {{ tab.title }}
      </span>
      <i v-if="closable" class="router-tab__item-close" @click.prevent.stop="closeTab(tab.id)" />
    </template>
  </RouterTab>
</template>

tab 对象字段 ​

字段类型说明
idstring页签唯一标识，取自路由匹配的 key
tostring页签对应的目标路径
titlestring?标题
tipsstring?悬浮提示
iconstring?图标 class
closableboolean?静态可关性（来自 meta.routerTab.closable）
tabClassstring | string[] | Record<string, boolean>自定义 class
hrefstring?外链地址
targetstring?外链打开方式

closable 不等于 tab.closable ​

作用域里的 closable 是计算值：

js
closable = tab.closable !== false && !(keepLastTab && items.length < 2)
1

即静态可关性与「keepLastTab 且仅剩 1 个页签」的动态判定共同决定。渲染关闭按钮请用作用域的 closable，用 tab.closable 会导致最后一个页签仍显示关闭按钮。

在插槽中调用实例方法 ​

必须惰性取实例

组件 setup 执行时，内层的 <RouterTab> 还没注册实例，顶层直接调 useRouterTab() 会抛错：

[vue-router-tab] useRouterTab() 需在挂载了 RouterTab 后调用
1

正确做法是在事件触发时才取用：

vue
<script setup>
import { useRouterTab } from 'vue-router-tab'

// ❌ setup 期实例未注册，抛错
// const tabs = useRouterTab()

// ✅ 事件触发时取用，此时实例已注册
function closeTab(id) {
  useRouterTab().closeTab(id)
}
</script>

样式定制 ​

插槽内容处于 .router-tab 作用域内，scoped 样式需用 :deep() 穿透：

vue
<style lang="scss" scoped>
.router-tab {
  :deep(.router-tab__slot-start),
  :deep(.router-tab__slot-end) {
    display: flex;
    align-items: center;
  }
}
</style>

完整示例 ​

vue
<template>
  <router-tab :class="{ 'is-fullscreen': fullscreen }">
    <!-- 页签开始：首页链接 -->
    <template #start>
      <router-link class="tab-slot-icon rt-icon-home" to="/slot/" title="首页" />
    </template>

    <!-- 页签结束：全屏切换（toggle 内切状态并调 adjust 重算页签滚动） -->
    <template #end>
      <a
        class="tab-slot-icon"
        :class="fullscreen ? 'rt-icon-fullscreen-exit' : 'rt-icon-fullscreen'"
        :title="fullscreen ? '退出全屏' : '全屏'"
        @click="toggle"
      />
    </template>

    <!-- 页签项插槽：v2 scope 为 { tab, closable } -->
    <template #default="{ tab, closable }">
      <i v-if="tab.icon" class="router-tab__item-icon" :class="tab.icon" />
      <span class="router-tab__item-title" :title="tab.tips || tab.title">{{ tab.title }}</span>
      <i v-if="closable" class="router-tab__item-close" @click.prevent.stop="closeTab(tab.id)" />
    </template>
  </router-tab>
</template>

<script setup lang="ts">
import { useRouterTab } from 'vue-router-tab'

import { useFullscreen } from '../composables/useFullscreen'

const { fullscreen, toggle } = useFullscreen()

/**
 * 关闭指定页签（惰性取实例）
 *
 * frame setup 期内层 <router-tab> 尚未注册实例，顶层调 useRouterTab() 会抛错，
 * 故在模板事件触发时才取用（此时实例已注册）。
 */
function closeTab(
  /** 页签 id */
  id: string
) {
  useRouterTab().closeTab(id)
}
</script>

<style lang="scss" scoped>
// 页签前后插槽容器
.router-tab {
  :deep(.router-tab__slot-start),
  :deep(.router-tab__slot-end) {
    display: flex;
    align-items: center;
  }
}

// 插槽内图标（首页 / 全屏）
.tab-slot-icon {
  margin: 0 5px;
  font-size: 20px;
  color: #2c3e50;
  text-decoration: none;
  cursor: pointer;

  &:active {
    opacity: 0.8;
  }
}
</style>
