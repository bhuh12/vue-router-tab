过渡效果 ​

APIDemo

RouterTab 有两个独立的过渡配置：

prop作用对象默认值
tabTransition页签项的增删动画'router-tab-zoom'
pageTransition页面内容的切换动画{ name: 'router-tab-swap', mode: 'out-in' }

两者类型均为 string | TransitionProps。

RouterTab 上没有 transition

不要写 <RouterTab transition="fade" /> —— RouterTab 没有 transition prop，不会生效也不会报错。

名为 transition 的 prop 只存在于 RouterAlive 上，且类型仅 string。

内置过渡 ​

库自带两个过渡效果（定义在 src/scss/transition.scss）：

名称效果
router-tab-zoom缩放淡入淡出，用于页签项
router-tab-swap位移交换，用于页面切换

传字符串 ​

只指定过渡名：

vue
<template>
  <RouterTab tab-transition="my-tab-fade" page-transition="my-page-fade" />
</template>

传对象 ​

传对象时即 Vue <Transition> 组件的 props，可用 name / mode / appear / duration 等全部字段：

vue
<template>
  <RouterTab :page-transition="pageTransition" />
</template>

<script setup>
const pageTransition = {
  name: 'my-page-fade',
  mode: 'out-in',
  appear: true
}
</script>

mode 的作用

mode: 'out-in' 让旧页面先离场再进场，避免两个页面同时可见导致的布局跳动。这也是 pageTransition 默认值带 mode 的原因。

tabTransition 默认值不带 mode —— 页签项是列表动画（<TransitionGroup>），增删需要同时进行。

禁用过渡 ​

传空字符串：

vue
<template>
  <RouterTab tab-transition="" page-transition="" />
</template>

完整示例 ​

vue
<template>
  <router-tab page-transition="page-fade" tab-transition="tab-scale" />
</template>

<style lang="scss" scoped>
// 页面 fade 过渡
:deep(.page-fade-enter-active),
:deep(.page-fade-leave-active) {
  transition: opacity 0.5s;
}

:deep(.page-fade-enter-from),
:deep(.page-fade-leave-to) {
  opacity: 0;
}

// 页签 scale 过渡
:deep(.tab-scale-enter-active),
:deep(.tab-scale-leave-active) {
  transition:
    opacity 0.5s,
    transform 0.5s;
}

:deep(.tab-scale-enter-from),
:deep(.tab-scale-leave-to) {
  transform: scale(1.5);
  opacity: 0;
}
</style>
