右键菜单 ​

APIDemo

contextmenu prop 控制页签右键菜单，类型 boolean | (BuiltinMenuId | ContextmenuItemConfig)[]，默认 true。

禁用菜单 ​

vue
<template>
  <RouterTab :contextmenu="false" />
</template>

内置菜单项 ​

内置项共 6 个，默认顺序即下表顺序：

id说明禁用条件
refresh刷新当前选中页签无
refreshAll刷新全部缓存页签无
close关闭选中页签页签不可关闭，或 keepLastTab 下仅剩 1 个
closeLefts关闭左侧页签左侧无可关闭页签
closeRights关闭右侧页签右侧无可关闭页签
closeOthers关闭其他页签无其他可关闭页签

自定义菜单项顺序 ​

传数组，用 id 字符串引用内置项：

vue
<template>
  <RouterTab :contextmenu="['refresh', 'close', 'closeOthers']" />
</template>

添加自定义项 ​

数组元素也可以是配置对象，与内置 id 混用：

vue
<template>
  <RouterTab :contextmenu="menu" />
</template>

<script setup>
const menu = [
  'refresh',
  'close',
  {
    id: 'copy-path',
    title: '复制路径',
    icon: 'rt-icon-copy',
    tips: '把页签地址复制到剪贴板',
    class: 'my-menu-item',
    handler: ({ target }) => {
      if (target) navigator.clipboard.writeText(target.to)
    }
  }
]
</script>

配置字段 ​

字段类型说明
idstring?菜单项 id；用内置 id 时会复用内置文案
titlestring | (ctx) => string标题，优先于内置文案
iconstring | (ctx) => string图标 class
tipsstring?悬浮提示
classstring?自定义 class
visibleboolean | (ctx) => boolean是否显示，默认 true
enableboolean | (ctx) => boolean是否启用，默认 true
handler(ctx) => void点击处理

title / icon / visible / enable 都支持传函数，入参为下文的上下文对象，可实现动态文案与状态。

handler 上下文 ​

字段类型说明
$tabsRouterTabInstanceRouterTab 实例
dataContextmenuData右键定位数据：{ id, index, left, top }
targetTab | undefined右键选中的页签
leftsTab[]选中项左侧的可关闭页签
rightsTab[]选中项右侧的可关闭页签
othersTab[]除选中项外的可关闭页签
closeMulti(tabs: Tab[]) => Promise<void>批量关闭页签

利用上下文实现「关闭左侧」这类批量操作：

js
{
  id: 'close-lefts-force',
  title: '强制关闭左侧',
  enable: ({ lefts }) => lefts.length > 0,
  handler: ({ lefts, closeMulti }) => closeMulti(lefts)
}

手动唤起菜单 ​

js
import { useRouterTab } from 'vue-router-tab'

const tabs = useRouterTab()

// 在指定坐标为指定页签唤起菜单
// 参数：页签 id、页签索引、鼠标事件（可选，用于定位菜单坐标）
tabs.showContextmenu(tab.id, index, event)

// 关闭菜单
tabs.hideContextmenu()

菜单文案国际化 ​

内置项文案取自语言包的 contextmenu.*（6 项，与内置 id 一一对应），详见国际化。

自定义项的 title 需要自行处理多语言，可在函数式 title 里调用 $tabs.i18nText()：

js
{
  id: 'my-item',
  title: ({ $tabs }) => $tabs.i18nText('i18n:myItem')
}

完整示例 ​

vue
<template>
  <RouterTab :class="{ 'is-fullscreen': fullscreen }" :contextmenu="contextmenu" />
</template>

<script setup lang="ts">
import { computed } from 'vue'
import type { BuiltinMenuId, ContextmenuItemConfig } from 'vue-router-tab'

import { useFullscreen } from '../composables/useFullscreen'

const { fullscreen, toggle } = useFullscreen()

/**
 * 右键菜单配置（对照 v1，v1 的 $menu 入参改为扁平 ContextmenuContext）
 *
 * 用 computed 包裹使函数式 title/icon 能读到最新 fullscreen.value。
 */
const contextmenu = computed<(BuiltinMenuId | ContextmenuItemConfig)[]>(() => [
  // 内置项
  'refresh',

  // 扩展内置：加图标
  { id: 'close', icon: 'rt-icon-close' },

  // 扩展内置：改执行方法（v1 $menu.closeMulti(others) → 扁平解构）
  {
    id: 'closeOthers',
    handler: ({ closeMulti, others }) => {
      closeMulti(others)
      alert('关闭其他页签')
    }
  },

  // 完全自定义（自定义 id 不在语言包，须显式给 title）
  {
    id: 'custom',
    title: '自定义操作',
    tips: '这是一个自定义操作',
    icon: 'rt-icon-doc',
    class: 'custom-action',
    // items 已解包为数组，直接用无 .value
    visible: (ctx) => ctx.$tabs.items.length < 3,
    enable: (ctx) => !(ctx.data.index % 2),
    handler: (ctx) => {
      console.log(ctx)
      alert('这是自定义操作，请打开控制台查看输出参数')
    }
  },

  // 有状态项：全屏（title/icon 函数式随状态变）
  {
    id: 'fullscreen',
    title: () => (fullscreen.value ? '退出全屏' : '全屏'),
    icon: () => (fullscreen.value ? 'rt-icon-fullscreen-exit' : 'rt-icon-fullscreen'),
    handler: () => setTimeout(toggle, 300)
  }
])
</script>
