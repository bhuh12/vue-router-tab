useRouterTab ​

useRouterTab(tabId?) 返回 RouterTabPublic，共 23 个字段（9 个数据 + 14 个方法）。

js
import { useRouterTab } from 'vue-router-tab'

const tabs = useRouterTab()
1
2
3

实例内部是 reactive() 对象，字段已自动解包 —— 直接读，不加 .value。其中 items 与 contextData 是 reactive 代理，可读也可写。

未挂载时抛错

[vue-router-tab] useRouterTab() 需在挂载了 RouterTab 后调用
1

父组件 setup 顶层调用会踩到（此时内层 RouterTab 未注册），需在事件触发时惰性取用。

RouterTab 没有 defineExpose，模板 ref 拿不到实例。

数据字段（9） ​

字段类型说明
itemsTab[]全部页签（可写）
activeTabIdstring当前激活页签 id
activeTabTab | undefined当前激活页签
langsRecord<string, any>当前语言文案
i18nText(text: unknown) => string取国际化文本
basePathstringRouterTab 所在父路由路径
iframesstring[]已挂载的 iframe url 列表
currentIframestring | null当前显示的 iframe url
contextDataContextmenuData右键菜单定位数据（可写）

open(path: RouteLocationRaw, isReplace?: boolean, refresh?: boolean | 'sameTab'): Promise<void>
open(arg: OpenArg): Promise<void>
1
2

位置参默认值：isReplace = false，refresh = true（默认全新打开）。

OpenArg：

字段类型说明
toRouteLocationRaw目标路径
replaceboolean?是否 replace 导航
refreshboolean?是否刷新
isSameTabboolean?仅命中同页签时刷新（位置参写法仍兼容）

ts

1

CloseArg：

字段类型默认说明
idstring?—目标页签 id，与 path 二选一
pathRouteLocationRaw?—按路径定位；两者都不传则关当前页签
matchboolean?truepath 是否精确匹配
forceboolean?true跳过 beforePageLeave
toRouteLocationRaw | null?—关闭后跳转；null 表示不跳转；不传则跳相邻页签
refreshboolean?false是否全新打开跳转地址

refreshAll ​

ts
refreshAll(force?: boolean): Promise<void>
1

默认 force = false。单个页面阻止刷新不影响其余页面。

reset ​

ts
reset(to?: RouteLocationRaw): void
1

清缓存 + 清恢复存储 + 重建初始页签 + 跳默认页。默认跳 defaultPage，缺省用 basePath。
