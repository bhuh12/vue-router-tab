tabs ​

初始展示的页签。PresetTab = string | (Partial<Omit<Tab, 'to'>> & { to: RouteLocationRaw })。

有恢复数据时优先恢复，不走此项。详见初始页签。

restore ​

true 用默认存储 key，字符串作为 key 后缀。数据存 sessionStorage。详见页签恢复。

append ​

'last' 插入末尾，'next' 插入当前页签之后。详见页签行为。

keepLastTab ​

true 时最后一个页签不可关闭，尝试关闭提示 msg.keepLastTab。

此项参与插槽 closable 的计算，详见页签插槽。

dragsort ​

页签拖拽排序开关。详见页签行为。

keepAlive ​

是否缓存页面。可被路由 meta.routerTab.keepAlive 覆盖。详见页签缓存。

maxAlive ​

最大缓存页数，0 为不限制。超出按 LRU 驱逐最早的非当前页签缓存（页签本身不关闭）。

reuse ​

同 key 的不同地址是否复用一个组件实例。true 时组件不重新挂载，页面需自行监听路由参数变化。

tabTransition ​

页签项的增删动画，作用于 <TransitionGroup>。传对象时即 Vue <Transition> 的 props。

内置 router-tab-zoom。详见过渡效果。

pageTransition ​

页面内容的切换动画。默认值带 mode: 'out-in'，避免两个页面同时可见。

内置 router-tab-swap。

RouterTab 上没有 transition prop

过渡配置只有 tabTransition 与 pageTransition 两个。名为 transition 的 prop 只在 RouterAlive 上。

contextmenu ​

false 禁用菜单；数组自定义菜单项与顺序。详见右键菜单。

lang ​

'auto' 取 navigator.language 前两位、未命中回退 en；也可传 'zh' / 'en' 或自定义语言对象。

内置语言只有 zh 与 en。详见国际化。

pageScroller ​

frame 级滚动容器选择器。在页面侧会被加 $ 前缀，即按 document 级查找。

页面级配置见 useRouterPage。详见滚动条。

tabId ​

多实例标识。useRouterTab(tabId) 按此取对应实例。详见多实例。

iframeAttrs ​

按 url 返回 <iframe> 的附加属性（如 sandbox / referrerpolicy）。不能覆盖库固定的 src 与 name。

详见 iframe 页签。

事件 ​

RouterTab 只有两个事件：

事件参数触发时机
iframe-mounted(url: string, el: HTMLIFrameElement)iframe 节点挂载就绪
iframe-loaded(url: string, el: HTMLIFrameElement)iframe 内容加载完成

iframe-loaded 来自原生 load 事件，iframe 内部导航同样触发。

插槽 ​

RouterTab 只有三个插槽：

插槽作用域说明
default{ tab: Tab, closable: boolean }自定义页签项内容
start无页签栏左侧
end无页签栏右侧

closable 不等于 tab.closable

作用域的 closable 是计算值：

js
closable = tab.closable !== false && !(keepLastTab && items.length < 2)
1

渲染关闭按钮请用作用域的 closable。

详见页签插槽。

key 的取值规则 ​

内置规则只有 2 个（大小写不敏感）：

规则名取值

fullpathroute.fullPath

beforePageLeave ​

参数顺序是 (tab, type)

tab 在前、type 在后。

PageLeaveType 共 5 个取值：close / refresh / leave / replace / unload。

返回值直接交给 next()：

返回值行为
undefined放行
字符串 / false阻止离开
location改为跳转该地址
throw / reject等价 next(false)

守卫为 router 级，只绑定首个实例

leave 与 replace 经由路由守卫触发，多实例下只有首个挂载的实例生效。close / refresh / unload 不受此限制。

详见离开页面提示。

routeTab ​

RouteTabInput = string | Partial<Tab>。传字符串等价于只设 title。

逐字段 patch 到当前页签，跳过 id 与 to。ref / computed 走 deep 深度监听；裸值只在 setup 时应用一次。

详见动态页签信息。

Props（4） ​

prop类型默认值说明
keepAlivebooleanfalse是否缓存
reusebooleanfalse同 key 复用实例
maxnumber0最大缓存数（0 不限制，超出 LRU 驱逐）

默认值与 RouterTab 不同

RouterAlive 的 keepAlive 默认 false，而 RouterTab 是 true。
