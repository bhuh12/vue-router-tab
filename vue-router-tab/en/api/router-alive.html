RouterAlive ​

Cache container component that RouterTab depends on internally. Can also be used standalone as a pure cache container (when a tab bar isn't needed).

vue
<template>
  <RouterAlive ref="aliveRef" keep-alive :max="5" transition="fade" />
</template>

2
3

Props ​

propTypeDefaultDescription
keepAlivebooleanfalseWhether to cache
reusebooleanfalseReuse instance for the same key
maxnumber0Max cache count (0 unlimited, LRU eviction when exceeded)
transitionstring''Page transition effect name

Defaults differ from RouterTab

RouterAlive's keepAlive defaults to false, while RouterTab's defaults to true.

Also note transition's type is only string, it does not accept an object — unlike RouterTab's pageTransition.

Events ​

EventParametersDescription
ready(alive: RouterAliveExpose)First route ready, emits the instance
change(type: 'create' | 'update', match: RouteMatch)Page created / updated

defineExpose ​

RouterAlive is the only component whose instance can be obtained via a template ref (RouterTab has no defineExpose).

RouterAliveExpose:

MemberTypeDescription
evict(...keys: string[]) => voidEvict specified caches
refresh(k?: string) => voidRefresh cache, defaults to the current key
alivePathOf(k: string) => string | undefinedGet the cached alivePath
aliveKeysstring[]List of currently alive cache keys (already unwrapped, a plain array)
routeMatchRouteMatchCurrent route match info
vue
<script setup>
import { ref } from 'vue'

const aliveRef = ref()

function clearCache() {
  aliveRef.value.evict('some-key')
}
</script>
