Vue Router TabA route-based tab bar component for Vue Router

Simple to configure. Tabs follow the route, with support for caching, iframes, and multiple instances.

Get Started →
View on GitHub

  • Simplicity First

    Simple to configure. Just import the component, then set tab info via the route's meta.routerTab and it runs.

  • Customizable Rules

    Easy to customize tab rules. Beyond the default rule, you can control how each route opens tabs, both globally and precisely.

  • Powered by Vue Router

    Tabs respond to Vue Router navigation, so you get all the power Vue Router provides.
