Iframe Tabs ​

APIDemo

RouterTab supports embedding external sites via iframe tabs.

Injecting the Built-in Routes ​

Must be injected manually

Without injecting the built-in routes, openIframe() navigation will fail.

js
import { createRouter, createWebHistory } from 'vue-router'
import { RouterTabRoutes } from 'vue-router-tab'

export default createRouter({
  history: createWebHistory(),
  routes: [
    {
      path: '/',
      component: Frame,
      children: [
        // Inject into the children of the level where <RouterTab> lives
        ...RouterTabRoutes
        // ...other page routes
      ]
    }
  ]
})

RouterTabRoutes contains only one relative route:

iframe/:src/:title?/:icon?
1

The first param is named src

Not url. The tab path looks like {parentPath}/iframe/{encodeURIComponent(src)}/{title}/{icon}.

For multiple instances, each level where a RouterTab lives needs its own injection.

Tab Operations ​

js
import { useRouterTab } from 'vue-router-tab'

const tabs = useRouterTab()
const src = 'https://bhuh12.github.io/vue-router-tab/'

// Open: arguments are the link, tab title, icon
tabs.openIframe(src, 'Docs', 'rt-icon-web')

// Close (src is required)
tabs.closeIframe(src)

// Refresh (src is required)
tabs.refreshIframe(src)

All three methods locate the tab by src

closeIframe / refreshIframe can't omit src — internally they look up the tab path via getIframePath(src).

Events ​

EventFires whenArguments
iframe-mountedThe iframe node is mounted(url, el)
iframe-loadedThe iframe content finishes loading(url, el)
vue
<template>
  <RouterTab @iframe-mounted="onIframeMounted" @iframe-loaded="onIframeLoaded" />
</template>

<script setup>
function onIframeMounted(url, el) {
  console.log('Node ready', url, el)
}

function onIframeLoaded(url, el) {
  console.log('Content loaded', url, el)
}
</script>

Navigating inside the iframe also triggers loaded

iframe-loaded comes from the <iframe>'s native load event, which also fires when the user navigates inside the iframe.

This is RouterTab's entire event list — there are only these two.

Customizing iframe Attributes ​

The iframeAttrs prop lets you attach attributes to the <iframe> node, taking the current url as an argument:

vue
<template>
  <RouterTab :iframe-attrs="getAttrs" />
</template>

<script setup>
function getAttrs(url) {
  return {
    sandbox: 'allow-scripts allow-same-origin',
    referrerpolicy: 'no-referrer'
  }
}
</script>

Security Filtering ​

The component filters the src protocol: addresses starting with javascript: or data: (case-insensitive) are replaced with about:blank to avoid XSS.

Other addresses are used as-is, so you should still configure sandbox when embedding untrusted third-party addresses (see previous section).

Caching Behavior ​

The cache key rule for iframe tabs is iframe-${src}. The iframe node is lifted outside KeepAlive and toggled with v-show — remounting via KeepAlive would lose the iframe's internal state.

When refreshing an iframe tab, since the <iframe> node is reused by url and an unchanged src won't auto-reload, the component internally resets src (reassigning the same value) to trigger a native browser reload — this approach isn't subject to cross-origin restrictions.

See Internals for implementation details.

Full Example ​

vue
<template>
  <RouterTab
    :iframe-attrs="getIframeAttrs"
    @iframe-mounted="iframeMounted"
    @iframe-loaded="iframeLoaded"
  />
</template>

<script setup lang="ts">
/** iframe 挂载（对照 v1）；第二参为 iframe DOM 元素 */
function iframeMounted(url: string, el: HTMLIFrameElement) {
  console.log('[iframe-mounted]', url, el.tagName)
}

/** iframe 加载完成（对照 v1）；第二参为 iframe DOM 元素 */
function iframeLoaded(url: string, el: HTMLIFrameElement) {
  console.log('[iframe-loaded]', url, el.tagName)
}

/** 按 url 返回 iframe 额外属性与事件（v1 无此能力） */
function getIframeAttrs(url: string) {
  return {
    sandbox: 'allow-scripts allow-same-origin allow-forms',
    referrerpolicy: 'no-referrer',

    // 用户自己的 onLoad，与组件 iframe-loaded 事件并存、都会触发
    onLoad: () => console.log('[iframeAttrs.onLoad]', url),

    onError: (e: Event) => console.error('[iframeAttrs.onError]', url, e)
  }
}
</script>

The iframe operations page:

vue
<template>
  <div>
    <h3>Iframe 页签操作</h3>

    <p>
      <a class="demo-btn" @click="$tabs.openIframe(site.src, site.title, icon)">
        打开“{{ site.title }}”
      </a>

      <a class="demo-btn" @click="$tabs.refreshIframe(site.src)"> 刷新“{{ site.title }}” </a>

      <a class="demo-btn" @click="$tabs.closeIframe(site.src)"> 关闭“{{ site.title }}” </a>
    </p>

    <p>
      <a
        class="demo-btn"
        title="XSS 跨站链接的 iframe 将展示空白页面"
        @click="$tabs.openIframe(xss.js, 'XSS - JS', icon)"
      >
        XSS - JS
      </a>

      <a
        class="demo-btn"
        title="XSS 跨站链接的 iframe 将展示空白页面"
        @click="$tabs.openIframe(xss.base64, 'XSS - Base64', icon)"
      >
        XSS - Base64
      </a>
    </p>

    <h3>打开 Iframe 页签</h3>

    <div class="custom-iframe">
      <label class="custom-iframe__field">
        名称：
        <input
          v-model="iframe.title"
          class="custom-iframe__input"
          name="title"
          placeholder="页签标题"
        />
      </label>

      <label class="custom-iframe__field">
        网址：
        <input
          v-model="iframe.src"
          class="custom-iframe__input"
          name="src"
          placeholder="请输入完整的网址"
        />
      </label>

      <a
        class="demo-btn primary"
        @click="iframe.src && $tabs.openIframe(iframe.src, iframe.title, icon)"
      >
        打开页签
      </a>
    </div>

    <template v-if="/^\/iframe\//.test(route.path)">
      <h3 class="text-strong">提示：</h3>

      <p>
        开启浏览器开发者工具的 console 页签，打开 Iframe 页签并查看
        <code>iframe-mounted</code>
        和
        <code>iframe-loaded</code>
        事件的参数打印
      </p>
    </template>
  </div>
</template>

<script setup lang="ts">
import { reactive } from 'vue'
import { useRoute } from 'vue-router'

import { useRouterTab } from 'vue-router-tab'

const $tabs = useRouterTab()
const route = useRoute()

/** iframe 页签图标 */
const icon = 'rt-icon-web'

/** 快捷站点（cn.vuejs.org 禁止 iframe 嵌入，改用自身文档站） */
const site = {
  /** 站点地址 */
  src: 'https://bhuh12.github.io/vue-router-tab/',

  /** 站点标题 */
  title: 'Vue Router Tab 文档'
}

/** 自定义打开的 iframe 表单 */
const iframe = reactive({
  /** iframe 地址 */
  src: 'https://router.vuejs.org/zh/',

  /** iframe 标题 */
  title: 'Vue Router'
})

/** XSS 输入防护演示用的危险链接 */
const xss = {
  /** javascript: 协议 */
  js: 'javascript:alert(1)',

  /** base64 内联 HTML */
  base64: 'data:text/html;base64,' + window.btoa('<script>alert(1)</s' + 'cript>')
}
</script>
