Internationalization ​

APIDemo

Internationalization has two parts: the component's own text (the lang prop) and business text like tab titles (the i18n prop).

Component Text: lang ​

lang is typed string | Record<string, any>, defaulting to 'auto'.

Built-in Languages ​

There are only two built-in languages: zh and en.

vue
<template>
  <RouterTab lang="en" />
</template>

Auto Detection ​

When lang="auto" (the default), the first two characters of navigator.language are used; if it doesn't match a built-in language, it falls back to en:

js
// navigator.language = 'zh-CN' → 'zh' → matches built-in zh
// navigator.language = 'ja-JP' → 'ja' → no match, falls back to en

Custom Language Object ​

When passing an object, the full structure must be provided:

vue
<template>
  <RouterTab :lang="myLang" />
</template>

<script setup>
const myLang = {
  tab: {
    untitled: '無題'
  },
  contextmenu: {
    refresh: '更新',
    refreshAll: 'すべて更新',
    close: '閉じる',
    closeLefts: '左側を閉じる',
    closeRights: '右側を閉じる',
    closeOthers: '他を閉じる'
  },
  msg: {
    keepLastTab: '少なくとも1つのタブを保持してください',
    i18nProp: '"i18n" メソッドを提供してください'
  }
}
</script>

The Lang Type Isn't Exported

The library doesn't export a Lang type; when writing a custom language object, declare the structure yourself, or copy the fields from the example above.

Field list (9 total):

PathDescription
tab.untitledPlaceholder text for untitled tabs
contextmenu.refreshContext menu "Refresh"
contextmenu.refreshAllContext menu "Refresh All"
contextmenu.closeContext menu "Close"
contextmenu.closeLeftsContext menu "Close Left"
contextmenu.closeRightsContext menu "Close Right"
contextmenu.closeOthersContext menu "Close Others"
msg.keepLastTabMessage shown when attempting to close the last tab
msg.i18nPropWarning text shown when the i18n method isn't provided

Business Text: i18n ​

Text like tab titles that comes from route meta is handed off to your i18n library via the i18n prop:

ts
i18n?: (key: string, params?: unknown[]) => string
1

Integrating with vue-i18n ​

vue
<template>
  <RouterTab :i18n="translate" />
</template>

<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

function translate(key, params) {
  return t(key, params)
}
</script>

Marking i18n Keys in meta ​

Two ways to write it:

js
// 1. String form: `i18n:` prefix
meta: {
  routerTab: {
    title: 'i18n:route.userList'
  }
}

// 2. Array form: first item is the key, the rest are params
meta: {
  routerTab: {
    title: ['route.userDetail', 'Alice']
  }
}

Plain strings without the i18n: prefix are displayed as-is, without going through translation.

Key Configured but No i18n Method Passed

The component logs a console warning once (using the msg.i18nProp text) and displays the key as-is.

Dynamic Titles Are Supported Too ​

The return value of a function-style title also goes through i18n resolution:

js
meta: {
  routerTab: {
    title: (route) => ['route.page', route.params.id]
  }
}

Manual Invocation ​

useRouterTab() exposes i18nText and the current language pack:

js
const tabs = useRouterTab()

tabs.i18nText('i18n:route.userList') // goes through the i18n method
tabs.i18nText('plain text') // returned as-is
tabs.langs.tab.untitled // read the current language pack

Switching Languages ​

The component's language reacts to changes in the lang prop — just drive it with a ref:

vue
<template>
  <RouterTab :lang="lang" />
  <button @click="lang = 'en'">English</button>
</template>

<script setup>
import { ref } from 'vue'

const lang = ref('zh')
</script>

Full Example ​

Language switching frame:

vue
<template>
  <RouterTab :i18n="i18n" :tabs="tabs" />
</template>

<script setup lang="ts">
import { ref, computed, provide } from 'vue'

import { LANG_KEY, type LangSwitcher } from './I18n.shared'

/** 语言包（对照 v1 frames/I18n.vue） */
const langs: Record<string, Record<string, string>> = {
  en: { i18n: 'I18n Page', page: 'Page {0}' },
  zh: { i18n: '国际化页面', page: '页面 {0}' }
}

/** 当前语言 */
const currentLang = ref('en')

/** 当前语言文案 */
const lang = computed(() => langs[currentLang.value] || langs.en)

/** 初始页签，标题用 i18n key 数组式 */
const tabs = [
  '/i18n/lang',
  { to: '/i18n/page/1', title: ['page', 1] },
  { to: '/i18n/page/2', title: ['page', 2] }
]

/** 翻译函数（对照 v1，支持 {0} 占位符） */
function i18n(key: string, params: any[] = []) {
  const text = lang.value[key]
  return text ? text.replace(/\{(\d+)\}/g, (_m, i) => params[i] ?? '') : key
}

/** 语言切换器（替代 v1 Vue.prototype.$lang），provide 给子页面 */
const switcher: LangSwitcher = {
  set: (l) => (currentLang.value = l),
  get: () => currentLang.value,
  list: () => Object.keys(langs)
}
provide(LANG_KEY, switcher)
</script>

Shared switcher definition:

ts
import type { InjectionKey } from 'vue'

/** 语言切换器（替代 v1 Vue.prototype.$lang，供 I18n frame 与 I18nPage 共享） */
export interface LangSwitcher {
  /** 切换到指定语言 */
  set: (lang: string) => void

  /** 取当前语言 */
  get: () => string

  /** 取所有可选语言 */
  list: () => string[]
}

/** 语言切换器注入 key */
export const LANG_KEY: InjectionKey<LangSwitcher> = Symbol('demo-lang')

Custom language pack:

vue
<template>
  <RouterTab :lang="customLanguage" />
</template>

<script setup lang="ts">
/** 自定义组件语言包（对照 v1 LangCustom.vue） */
const customLanguage = {
  /** 页签相关文案 */
  tab: {
    /** 未命名页签的默认标题 */
    untitled: 'Untitled Page'
  },

  /** 右键菜单文案 */
  contextmenu: {
    /** 刷新 */
    refresh: 'Refresh This',
    /** 刷新全部 */
    refreshAll: 'Refresh All',
    /** 关闭 */
    close: 'Close This',
    /** 关闭左侧 */
    closeLefts: 'Close to the Left',
    /** 关闭右侧 */
    closeRights: 'Close to the Right',
    /** 关闭其他 */
    closeOthers: 'Close Others'
  },

  /** 提示文案 */
  msg: {
    /** 最后一个页签禁止关闭的提示 */
    keepLastTab: 'Keep at least 1 tab',
    /** 未传 i18n prop 却用了 i18n key 时的告警文案 */
    i18nProp: 'Please set the i18n prop of RouterTab'
  }
}
</script>
